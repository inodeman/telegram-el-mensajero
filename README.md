# Telegram: El mensajero

Documental de **15:00**, formato YouTube 16:9 (1280×720), narrado en español.

Historia de Telegram desde VKontakte y el exilio de Pavel Durov hasta el bloqueo ruso, el caso TON, el cruce de los mil millones de usuarios y la investigación abierta en Francia. Las causas penales se cuentan como acusaciones, no como condena.
